Updates made to Figure 12 (based on adm/views.py):

  • Added Validate Admin Access — analytics views require an authenticated staff account.
  • Added Select Analytics Period — Last 7 Days, Last 30 Days, All Time, or a specific month (period picker feeds the AJAX refresh).
  • Compute and Prepare Analytics (AJAX) — consolidated the old "retrieve" chains into one step listing the actual metrics: total reports, counts per status, category trends, building hotspots, resolution-time buckets, and average satisfaction.
  • Report type corrected — the two PDF outputs are the Dashboard Report (export_dashboard_report_pdf) and the Personnel Performance (QQT) Report (export_personnel_performance_pdf), not a survey branch.
  • NEW: "Last day of month or month specified?" decision — without an explicit month, the monthly Dashboard Report is blocked (403) except on the last day of the month; admins may backfill any month via the month picker.
  • NEW: Editable summary — system fetches a suggested narrative summary and prefills a textarea; the admin's edited text wins (even if blank, the SUMMARY section is omitted).
  • Compile step embeds client-captured chart images (status, categories, buildings, resolution) into the report.
  • NEW: "Generation successful?" decision — PDF rendering failure shows an error message instead of silently ending.
  • Output — PDF is streamed inline (Dashboard_Report_YYYY-MM.pdf) for the admin to download or print.

Dashed node = optional admin action. Open in any browser; print with Ctrl+P for a clean copy.
