Figure 9 — Admin Report Processing

For Admins
Admin
1Log in to the Admin Dashboard.
2Open the report list and click on a submitted report to review it.
3Fill in the review form:
• Choose a Category and fill in any Custom Category if needed.
• Set a Priority.
• Select the People working on the report.
• Tick the Pending boxes that apply (e.g., awaiting approval, awaiting materials).
↓
Is the report complete?
4aConfirm it is ready for the student.
4bShow what is still missing. The report stays in Pending until everything is filled in.
System
1Check if the report is locked.
Show the review fields: category, custom category, priority, personnel, and pending items.
Validate the entry.
Is priority set, personnel assigned, and all pending boxes checked?
If yes: move the report to In Progress so the work begins.
If no: list what is missing and keep the report in Pending.
↓
Is this the final solution?
If yes: keep the report in a "Resolved" state so the student can share feedback.
If no: start over so more work can be done.
↓
2Send a status update to the student's dashboard and email.
↓
[ END ]

Remember: a report only becomes In Progress when everything is ready — priority, personnel, and all pending boxes. If anything is missing, the report stays Pending and the admin sees a clear list of what is missing.

Figure 10 — Client Satisfaction Survey

For Students
Student
1Log in and open the report you submitted.
2Click the link that says your report is now resolved.
Have you already shared feedback on this report?
Read the short survey.
Give a rating from 1 (Unsatisfactory) to 5 (Outstanding).
Write comments if you want to, then submit.
↓
Thank you message.
System
1Check the report status. A survey only appears after the report is marked Resolved.
Check if the student has already answered.
Has the student already answered?
Show the rating choices (1–5).
Save the rating and comments.
Close the report once the student submits.
Notify the admins that the student's feedback has been received.
↓
[ END ]

This survey is required to officially close the report. The student's rating and comments go directly to the maintenance team so they can improve service.

Figure 11 — FAQ Chatbot

For Students & Staff
Student / Staff
1Open the chatbot on the Dashboard or in the menu.
2Type a question about the system or their report.
Wait for the answer.
↓
Did the chatbot answer well?
If you were not helped, open a new report or contact IT Support.
System
1Read the question.
Match it against the official FAQ base. The bot only answers using the system's own guide.
Is the question in the FAQ guide?
If yes: send the answer from the guide.
If no: say it does not have the information and suggest contacting support.
↓
[ END ]

The bot never guesses. If the answer is not in the official guide, it tells the user and points them to the right person for help.

Figure 13 — Notification Flow

In-App + Email
Student / Staff
1Log in and look at the bell icon on the Dashboard.
2See your notifications. Unread ones have a small red badge.
Click "All" or "Unread" to filter what you see.
3Open a notification to see the details of your report.
It marks the item as Read.
4Click "Mark All as Read" when you have finished.
System
1Show the new notification in two ways:
In-app: a new entry appears in the bell icon with a red badge.
Email: you also receive an email with the same message.
Record who gets it:
• When a report is submitted → all admins
• When the status changes to In Progress → the student
• When the report is Resolved → the student + all admins
• When the report is Closed → the student + all admins
Show the latest 10 notifications as you scroll or click.
Is this notification unread?
When the user opens the bell, mark that notification as Read and take them to the report.
When the user clicks "Mark All as Read," mark every unread item as Read.
↓
[ END ]

Registration & Email Verification

New Student Sign-Up
Student
1Start at the sign-up screen.
2Type your details: name, email, password, program, and contact number.
3Submit the form.
↓
Did you miss something?
System creates your account with "Not yet verified" status.
System generates a 6-digit code and sends it to your email.
Did you get the email?
Type the 6-digit code into the box and submit.
System checks the code.
Is the code correct and not expired?
Your account is now active. You can log in.
[ END ]
System
1Check the form. If something is missing or looks wrong, show an error.
Save the account with email verification turned off.
Create a 6-digit code that expires in 10 minutes.
Send the code to the student's email.
Did the email send?
Check the code the student typed in.
Is the code right and within time?
Turn on email verification for the account.
Remove the code so it cannot be reused.
Send the student to the login screen.
↓
[ END ]

This flow is separate from the login flow. Login verifies a password; registration verifies the email address before the account can be used.
